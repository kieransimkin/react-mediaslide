# MediaSlide for WordPress

This plugin embeds the **real MediaSlide React component** in WordPress, with no runtime CDN dependency. It supports WordPress Media Library images, galleries stored in published posts (Gutenberg `core/gallery` and classic `[gallery ids="..."]`), and extension via `mediaslide_gallery_items` filter.

## Installation

From the repository root:

```sh
npm ci
npm install --no-save --package-lock=false vite@5 react-dom@18
npx vite build --config wordpress/vite.config.mjs
cd wordpress && zip -r mediaslide-wordpress.zip mediaslide/
```

Install the ZIP through **Plugins → Add New → Upload Plugin**. The GitHub Actions browser workflow builds and uploads the same ZIP as an artifact on successful runs.

## Gutenberg block

Insert **MediaSlide Gallery**, choose images using the WordPress media selector, optionally enter a published post ID containing gallery blocks, and set view mode and height. The front end renders the actual MediaSlide component.

## Shortcode

```
[mediaslide ids="12,34,56" mode="thumbnails" height="560"]
[mediaslide post_id="123" mode="slide" height="680"]
```

The post ID form extracts gallery attachment IDs from a published post. It does not automatically interpret arbitrary third-party gallery plugin databases. Integrators can map other gallery providers using the `mediaslide_gallery_items` filter. Only images are supported by default; video/audio requires a custom `renderFile` integration.

## Security and compatibility

Only publicly published gallery sources are read by post ID. Attachment URLs and titles are generated by WordPress, attributes are validated, and JSON is escaped before HTML output. The React component is bundled, not fetched from a third-party CDN. Existing `react-mediaslide` npm consumers are unaffected.

## Verification

Test with a WordPress 6.2+ installation, gallery block, shortcode, mobile layout, and editor media selector before production deployment. The repository build validates bundling; a real WordPress integration test still requires a WordPress test environment.
