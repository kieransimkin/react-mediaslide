# Contributing to MediaSlide

Start by comparing the latest GitHub release, npm `latest` dist-tag, current source tag and the version used by your test application. Run `npm ci` and `npm run check` before submitting a change.

Read [the ecosystem guide](docs/ECOSYSTEM.md) and consider the complete DanceFlow capability set. Keep reusable gallery behavior here and product-specific artwork, data fetching and scene choices in the consuming project. Add focused tests and update the public API guide for changed behavior.

Use actual interface captures for implemented behavior when a reproducible demo is available. Clearly label generated diagrams. This release supplies a generated architecture overview; an actual screenshot and video are intentionally deferred because the historical repository has no deterministic demo application yet.
